# 墨墨记忆卡（Markji）制卡语法完整参考

来源：墨墨开放 API 官方制卡指南（`open.maimemo.com/api_bundle.yaml` 的 `info.description`）
＋ 社区 FAQ《Markji 制卡语法关键指南》（含论坛真实卡片验证的补充能力）。
本文只收录已确认的语法，**未列出的标签不要凭标签名推测发明**。

---

## 0. 三条不可违反的原则

1. **`content` 是一整段完整语法文本**，不是「标题/答案/图片」等独立字段。改卡时保留原有语法骨架做局部修改，不要拆散重拼。
2. **真实换行属于语法**。必须是真实换行符，不能写成字面 `\n`，也不能为了「压缩」把整张卡拼成一行。
3. **`---` 是答案线**，独占一行、前后无空格、不能替换成别的横线或 HTML。若答案线在卡片末尾，其后仍保留一个真实换行。

---

## 1. 通用结构

```text
[名称#参数1,参数2#内容]
```

- 第一个 `#` 分隔名称与参数，第二个 `#` 分隔参数与内容。**没有参数时也必须保留两个 `#`**（`[E##x+y]`、`[Choice##`）。
- 标签名和参数**区分大小写**：`T` `P` `F` `Choice` `Pic` `Audio` `Card` `E`。
- 多参数用**半角逗号**分隔；标签名、参数、分隔符之间**不加空格**。
- 每个标签必须以未转义的 `]` 闭合。
- 普通段落直接写文字即可，**不需要** `[P##内容]`。

### 块级 vs 行内

| 类别 | 语法 | 位置要求 |
|---|---|---|
| 块级 | `[P#…#…]`、`[Choice#…#`、`[Pic#…#]`、**独立**公式 `[E##…]`、`---` | 必须从新一行的**第一个字符**开始 |
| 行内 | `[T#…#…]`、`[F#…#…]`、`[Audio#…#…]`、`[Card#…#…]`、**行内**公式 `[E##…]` | 可出现在段落任意位置 |

> 行内公式不受行首限制。只有作为独立块的公式才必须顶格、且闭合 `]` 后同行不再追加文字。

### 嵌套白名单

| 容器 | 允许放入 |
|---|---|
| 普通段落 | `T`、`F`、`Audio`、`Card`、行内 `E` |
| `[P#…]` | `T`、`F`、`Audio`、`Card` |
| `[Choice#…]` 选项 | `T`（官方）；`E` 已由真实卡片验证可用 ¹ |
| `[T#…]` 内容 | 不放任何标签 |
| `[F#…]` 内容 | 不放任何标签（公式挖空是反向嵌套，见 §6.3） |
| `[Audio#…]` / `[Card#…]` 显示文字 | 不放任何标签 |
| `[Pic#…#]` | 内容必须为空 |
| `[E##…]` | 只写 KaTeX 内容；做公式挖空时可放 `F` |

¹ 官方嵌套表尚未同步「选项中可用公式」这一项，但论坛真实卡片已验证渲染正常。
除「Choice 选项内的 E」和「E 内的 F」这两个已验证例外，**不要让行内语法互相嵌套**，也不要把两个例外叠成三层。

## 2. 转义

| 想显示 | 应输入 |
|---|---|
| `[` | `\[` |
| `]` | `\]` |

```text
数学中的闭区间可以写作 \[0,1\]。
[T#B#请阅读第 \[3\] 章]
```

- 只转义**作为普通文字显示**的中括号；语法本身的外层括号不要转义。
- 内容区中的 `#` 和半角逗号通常可直接写；**参数区**中的 `#`、半角逗号、换行具有结构含义，不能当普通字符。
- 反斜杠只在紧挨中括号时用于转义；公式里的 LaTeX 反斜杠按原样书写。
- 全角 `［］＃` 会改变实际字符，不再作为默认转义方案。

## 3. 段落 `P`

```text
[P#参数#段落内容]
```

| 参数 | 效果 | 说明 |
|---|---|---|
| `H1` | 标题 | **只支持 H1**，不要生成 H2/H3 |
| `L` | 无序列表项 | 当前只有无序列表，不要造有序列表 |
| `I<n>` | 缩进级别，`n` 为正整数 | 可与 `L` 组合做分级列表 |
| `left` / `center` / `right` | 对齐 | 一段只能选一种 |

```text
[P#H1,center#[T#B#幸存者偏差]]
[P#center#Survivorship Bias]
```

分级列表 + 挖空：

```text
[P#L#一级主题]
[P#L,I2#二级主题]
[P#L,I3#[F#1#需要回忆的三级主题]]
```

> 标题只是排版，**不代替答案线**。即使写了 `[P#H1#…]`，仍需显式写 `---`。
> 整个 `P` 标签尽量写在同一行。

## 4. 文字样式 `T`

```text
[T#参数#文字]
```

| 参数 | 效果 | 示例 |
|---|---|---|
| `B` | 加粗 | `[T#B#重点]` |
| `U` | 下划线 | `[T#U#关键词]` |
| `I` | 斜体 | `[T#I#术语]` |
| `D` | 删除线 | `[T#D#旧表述]` |
| `up` | 上标 | `x[T#up#2]` |
| `down` | 下标 | `H[T#down#2]O` |
| `!rrggbb` | 文字颜色 | `[T#!e53935#红色文字]` |
| `!!rrggbb` | 背景色 | `[T#!!fff2cc#高亮文字]` |
| `link/"URL"` | 超链接 | `[T#link/"https://markji.com"#访问网站]` |

**样式合并到同一个标签**，不要多层嵌套：

```text
✓ [T#B,U,!e53935#需要特别记忆的内容]
✗ [T#B#[T#U#重点]]
```

推荐参数顺序：`B,U,I,D,up,down,!文字色,!!背景色,link/"URL"`（用不到的省略）。

规则：
- 颜色是**不带 `#` 的 6 位小写十六进制**。`!ff0000` ✓，`!#ff0000` ✗，`!FF0000` ✗。
- `up` 与 `down` 不能同时使用；同一种参数不能重复。
- 链接 URL 两侧的**英文双引号是语法的一部分**，不能省略；建议带完整 `https://`。
- URL 中的 `#` 必须编码为 `%23`，半角逗号编码为 `%2C`（否则会破坏参数区）。`?` `&` `=` 可保留。

### HTML → Markji 映射

| HTML | Markji |
|---|---|
| `<b>` `<strong>` | `B` |
| `<u>` `<ins>` | `U` |
| `<i>` `<em>` | `I` |
| `<s>` `<strike>` `<del>` | `D` |
| `<sup>` | `up` |
| `<sub>` | `down` |
| `color` | `!rrggbb` |
| `background-color` | `!!rrggbb` |
| `<div>` `<p>` `<li>` `<br>` | 真实换行或相应段落 |

**不要把 HTML 原样写进卡片**，它会作为普通文字显示或格式全丢。

## 5. 挖空 `F`

```text
[F#编号#要隐藏的内容]
```

```text
光合作用主要发生在[F#1#叶绿体]中。
```

- 编号是**从 1 开始的正整数**，不能省略、不能用 `0`/负数/小数/文字。
- **相同编号 = 同一组**，一起显示或隐藏；不同编号是不同组。
- 普通挖空的内容中**不嵌套任何标签**；需要样式时把样式放到挖空外部。

## 6. 公式 `E`

```text
[E##<LaTeX 内容>]
```

由 **KaTeX** 渲染，能力边界以 KaTeX 官方函数支持表为准。

### 6.1 行内公式

```text
速度 [E##v] 是位移变化量 [E##\Delta x] 与时间变化量 [E##\Delta t] 的比值。
```

### 6.2 独立公式（顶格，闭合 `]` 后同行不再写文字）

```text
[E##E_k=\frac{1}{2}mv^2]
[E##x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}]
```

公式内容本身可以换行：

```text
[E##\begin{aligned}
a^2+b^2&=c^2
\end{aligned}]
```

### 6.3 公式挖空 —— 把 `F` 放进 `E`

```text
斜率公式是 [E##k=[F#1#\frac{\Delta y}{\Delta x}]]。
```

正确方向 `[E##前段[F#1#被挖空的LaTeX]后段]`；**不要反着写** `[F#1#[E##…]]`。

### 6.4 禁止事项

- 不要在 `[E##…]` 内再套定界符：`$…$`、`$$…$$`、`\(…\)`、`\[…\]` 全部错误。
- 必须保留 LaTeX 命令中的真实反斜杠（`\frac` `\Delta` `\sqrt`）。
- 一个完整公式尽量放进一个 `E`，不要无意义拆成相邻多个。
- 题号、解释文字放在 `E` 外面：`(1) [E##v=v_0+at]`。
- 不要编造 KaTeX 不支持的命令，也不要依赖额外 LaTeX 宏包。

## 7. 选择题 `Choice`

```text
[Choice#参数#
* 正确选项
- 错误选项
]
```

| 参数 | 含义 |
|---|---|
| （空） | 单选、选项随机排列 |
| `fixed` | 保持选项书写顺序 |
| `multi` | 多选 |
| `fixed,multi` | 多选且固定顺序 |

**类型由 `*` 的数量决定**：恰好一个 → `[Choice##`；两个及以上 → `[Choice#multi#`。

```text
[T#B#001Q 真题卡片]
下列哪一项是正确的？
[Choice##
* 正确选项
- 错误选项一
- 错误选项二
]
---
这里填写答案解析。
```

公式选项（已验证）：

```text
一元二次方程的求根公式是？
[Choice#fixed#
* [E##x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}]
- [E##x=\frac{-b\pm\sqrt{b^2+4ac}}{2a}]
]
---
正确答案为第一项。
```

结构要求：
- `[Choice…` 必须顶格；结束的 `]` 必须**独占一行**。
- 每个选项独占一行，以 `* `（正确）或 `- `（错误）开头，**符号后有一个空格**。
- `---` 放在完整选择块之后，用于分隔题目与解析。
- 选项内只用普通文字、`[T#…]`、`[E##…]`；不放挖空、音频、卡片引用、图片。
- 选项文字中的普通中括号用 `\[` `\]` 转义。

## 8. 媒体：图片 `Pic` 与音频 `Audio`

### 8.1 图片

```text
[Pic#ID/<fileId>#]              普通图片
[Pic#ID/<imageFileId>,MID/<maskFileId>#]   带遮罩
```

- 必须顶格，**内容区为空**，所以结尾是 `#]`。
- **相邻且无空格/换行**的多张图片组成同一个画廊：`[Pic#ID/a#][Pic#ID/b#]`
- 分行写则是两个独立图片区块。
- 参数顺序固定 `ID` 在前、`MID` 在后，中间是无空格的半角逗号，两者不能交换或留空。

### 8.2 音频

```text
[Audio#ID/<fileId>#<显示文字>]
```

| 参数 | 含义 |
|---|---|
| `ID/<fileId>` | 指定已有音频 |
| `M` | 手动播放 |
| `A` | 自动播放（不写 `M` 时也按自动处理） |
| `D` | 跟随用户设置 |

```text
[Audio#M,ID/1kIC9#点击播放发音]
[P#H1,center#[T#B#幸存者偏差][Audio#A,ID/1kIC9#]]
```

`M` 与 `A` 不能同时用。显示文字可为空但必须保留第二个 `#`，且其中不嵌套语法。

### 8.3 file.id 的硬性规则

- `<fileId>` 只能是**上传后返回的真实 Markji `file.id`**（见 `api.md` 的 `POST /files`）。
- **不能**写本地路径、原始文件名、下载 URL、Anki media member 或临时编造的 ID。
- **`file.id` 大小写敏感**，必须逐字符原样保留。`1lVnm` 与 `1lVNM` 是两份不同文件，禁止大小写归一化。
- Windows 文件系统不区分大小写：批量制卡时用「稳定序号＋原始 ID」命名本地文件（如 `0549-1lVnm.jpg`），并用 manifest 记录上传结果，回填时从 manifest 读 ID。

### 8.4 图片遮罩 `.msk1`

遮罩**不是图片**，而是描述遮挡矩形的 JSON 文件（`mime: markji/mask`）。

1. 先确定**最终原图**并记录像素宽 `W`、高 `H`。生成遮罩后**不得再裁剪/缩放/旋转原图**。
2. 记录每个遮挡矩形的左上 `(x1,y1)` 与右下 `(x2,y2)`（原点在图片左上角）。
3. 归一化到 `0～10000`：

   ```text
   left   = round(x1 / W * 10000)
   top    = round(y1 / H * 10000)
   width  = round((x2 - x1) / W * 10000)
   height = round((y2 - y1) / H * 10000)
   ```

4. 写成 UTF-8 的 JSON 数组，`index` 从 1 递增，当前只验证过 `"type": "rect"`：

   ```json
   [
     {"width": 3000, "height": 1250, "top": 2500, "left": 1000, "index": 1, "type": "rect"},
     {"width": 2000, "height": 1000, "top": 5000, "left": 6000, "index": 2, "type": "rect"}
   ]
   ```

5. 原图与 `.msk1` 分别上传取得各自 `file.id`，写成 `[Pic#ID/<原图>,MID/<遮罩>#]`。

预览图（半透明矩形叠加原图）只用于人工检查，**其 file.id 绝不能填进 `MID`**。

## 9. 链接与卡片引用

两者是不同能力，不能混用。

| 目标 | 语法 | 填入 |
|---|---|---|
| 外部网页 | `[T#link/"<URL>"#显示文字]` | 完整且正确编码的 URL |
| Markji 卡片 | `[Card#ID/<root_id>#显示文字]` | 目标卡片的 **`root_id`** |

```text
[T#B,!90959b,link/"https://example.com"#查看资料来源]
[Card#ID/mkjr_.UHFrGDWz8NVSSUN1NQ0GQ#参见相关卡片]
```

卡片引用规则：
- `ID` 必须是目标卡片的 `root_id`（API 返回的 `card.root_id`，形如 `mkjr_…`），**不是** `card.id`、`deck_id` 或 `file.id`。
- 关联多张卡片用**半角短横线 `-`** 连接，**最多 5 张**：`[Card#ID/<rid1>-<rid2>#…]`。不能用逗号/空格/换行。
- ID 本身不能包含用作分隔符的连字符；重复 ID 应去重，空 ID 应删除。
- 引用目标被删除或无权访问时会失效，生成后应实际点击验证。

## 10. 可复制模板

### 基础知识卡
```text
[P#H1,center#[T#B#<中文标题>]]
[P#center#<外文标题，可删除此行>]
---
<正文>
```

### 富文本知识卡
```text
[P#H1,center#[T#B#<标题>]]
---
<普通正文>
[T#B,U,!e53935#<加粗下划线红色的重点>]
[T#!!fff2cc#<带背景色的补充>]
[E##<KaTeX 公式>]
```

### 带图片和音频（两条答案线做分层揭示）
```text
[P#H1,center#[T#B#<标题>][Audio#ID/<audioFileId>#]]
---
[Pic#ID/<imageFileId>#]
---
<正文>
```
不需要分层时删掉图片后的第二条 `---`。需要遮罩时把图片行换成 `[Pic#ID/<原图>,MID/<遮罩>#]`。

### 真题卡（单选）
```text
[T#B#<序号>Q 真题卡片]
<题干>
[Choice##
* <唯一正确选项>
- <错误选项一>
- <错误选项二>
]
---
<解析>
```
多选把首行改成 `[Choice#multi#`；需固定顺序用 `fixed` / `fixed,multi`。

### 分级列表 + 挖空
```text
[P#H1#<标题>]
[P#L#<一级主题>]
[P#L,I2#<二级主题>]
[P#L,I3#[F#1#<需要回忆的三级内容>]]
---
<补充说明>
```

> 模板中所有 `<…>` 都是占位符，**必须替换**，不能原样写进正式卡片。

## 11. 常见错误速查

| # | 错误 | 后果 | 处理原则 |
|---|---|---|---|
| 1 | 删除/移动答案线 | 问答同面或顺序错乱 | 改动前后核对 `---` 的数量与位置 |
| 2 | 丢失真实换行（写成 `\n`） | 段落、选项、答案线粘连 | 以 UTF-8 文件的真实内容为准 |
| 3 | 标签未闭合 `[P#H1#[T#B#标题]` | 解析失败 | 每个 `[` 都要有对应 `]`，嵌套分别闭合 |
| 4 | 多层标签堆样式 `[T#B#[T#U#x]]` | 冗余、易错 | 合并成 `[T#B,U#x]` |
| 5 | HTML 直接贴入 | 标签变正文或格式全丢 | 先按 §4 映射转换 |
| 6 | 把文件名/URL 当 file.id | 媒体不显示 | 只用上传返回的 `file.id` |
| 7 | 改变 file.id 大小写 | 引用到别的媒体 | 当作大小写敏感的不可变字符串 |
| 8 | `ID` 与 `MID` 混淆/交换 | 遮罩错位或原图不显示 | 固定 `ID`=原图、`MID`=`.msk1` |
| 9 | 生成遮罩后又改原图 | 遮挡区域整体偏移 | 原图变化必须重算 `.msk1` |
| 10 | 公式仍用 `$…$` 或丢反斜杠 | 渲染失败 | 统一 `[E##…]`，保留 `\frac` 等反斜杠 |
| 11 | 多选题误用 `[Choice##` | 判分错误 | 先数 `*` 个数再决定是否加 `multi` |
| 12 | 链接 URL 没引号或没编码 | 链接打不开或破坏外层标签 | `link/"URL"`，`#`→`%23`，`,`→`%2C` |
| 13 | 卡片引用误用 `card.id` | 引用失效 | 只填 `root_id`，最多 5 个，短横线连接 |
| 14 | 挖空编号非法或公式挖空写反 | 无法分组/渲染 | `[F#正整数#…]`；公式挖空是 `E` 内嵌 `F` |
| 15 | 块级语法没顶格 | 不被识别为块 | `P`/`Choice`/`Pic`/独立 `E`/`---` 都顶格 |
| 16 | 普通中括号没转义 | 提前闭合外层标签 | 写成 `\[` `\]` |
| 17 | 把行内公式误当独立公式 | 不必要的排版断裂 | 只有独立公式受行首限制 |
| 18 | 写 Markdown 表格 / 代码块 / `#` 标题 / `**加粗**` | 原样显示成文本 | Markji **没有表格和代码块语法**；表格拆成 `[P#L#…]` 或多张卡，标题用 `[P#H1#…]`，加粗用 `[T#B#…]` |
| 19 | 用 `str.format()` / f-string 拼含 LaTeX 的正文 | 花括号被当占位符，报错或被吃掉 | 用 `@TOKEN@` 令牌配合 `str.replace()` |

## 12. 发布前检查清单

`markji.py lint` 已自动覆盖其中绝大多数；剩下的需人工核对。

**自动可查**
